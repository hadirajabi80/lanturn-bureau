# تخته نرد — نقشهٔ طراحی و پیاده‌سازی

## هدف
یک تخته نرد سه‌بعدی دونفره (روی یک دستگاه، کنار هم) با بالاترین کیفیت بصری و انیمیشن‌های روان ۶۰ فریم:
تاس‌هایی که واقعاً فیزیکی پرتاب می‌شوند، مهره‌هایی که با قوس طبیعی جابه‌جا می‌شوند و صفحه‌ای با هنر خاتم‌کاری ایرانی.

## فناوری
| لایه | انتخاب | چرا |
|---|---|---|
| ساخت | Vite + TypeScript | سریع، بدون سرور |
| رندر سه‌بعدی | three.js + React Three Fiber + drei | کیفیت PBR، سایهٔ نرم، بازتاب |
| فیزیک تاس | Rapier (WASM) | تاس با لبهٔ گرد، رفتار طبیعی |
| پس‌پردازش | postprocessing (Bloom, Vignette, SMAA) | درخشش ملایم و حس سینمایی |
| رابط کاربری | React + motion | انیمیشن‌های فنری پنل‌ها |
| وضعیت | zustand | ساده و بدون رندر اضافه |
| صدا | Web Audio (سنتز زنده) | بدون فایل صوتی، هم‌زمان با برخورد واقعی تاس |

هیچ تصویر یا مدل خارجی استفاده نمی‌شود؛ چوب گردو، نمد، خاتم و مثلث‌ها همگی به‌صورت رویه‌ای (procedural) روی Canvas ساخته می‌شوند.

## معماری
```
src/
  engine/      منطق خالص بازی (بدون React) — قوانین، حرکت‌های مجاز، امتیاز
  physics/     شبیه‌سازی تاس (Rapier) — از پیش محاسبه و ضبط مسیر
  scene/       صحنهٔ سه‌بعدی — صفحه، مهره‌ها، تاس‌ها، نور، دوربین، تعامل
  textures/    تولید بافت‌های رویه‌ای (چوب، خاتم، نمد، مثلث‌ها)
  audio/       سنتز صدا
  store/       وضعیت بازی + کارگردان انیمیشن
  ui/          رابط فارسی (RTL) — منو، نوار بازیکنان، دکمه‌ها، پایان بازی
```

### ۱. موتور قوانین (engine)
- نمایش صفحه: آرایهٔ ۲۴ خانه (مثبت = سفید، منفی = سیاه) + بار + بیرون‌رفته.
- تولید **همهٔ دنباله‌های مجاز** نوبت با رعایت کامل قوانین رسمی:
  - ورود از بار اجباری است.
  - باید بیشترین تعداد تاس ممکن بازی شود.
  - اگر فقط یکی از دو تاس قابل بازی است، تاس بزرگ‌تر اجباری است.
  - جفت = چهار حرکت.
  - خروج (بیرون بردن) فقط وقتی همه در خانه‌اند؛ با تاس بزرگ‌تر از دورترین مهره.
- حرکت ترکیبی (یک مهره با هر دو تاس) و نمایش مقصدهای چندمرحله‌ای.
- برگشت (Undo) در طول نوبت.
- امتیاز: برد ساده ۱، **مارس** ۲، **مارس کامل (بک‌گمون)** ۳؛ مسابقه تا ۱/۳/۵/۷ امتیاز.
- هر مهره هویت ثابت دارد تا انیمیشن هر مهره دقیقاً ردیابی شود.

### ۲. تاس فیزیکی (physics)
- نتیجه با `crypto.getRandomValues` تعیین می‌شود (کاملاً منصفانه).
- پرتاب در یک جهان Rapier جداگانه **در چند میلی‌ثانیه** شبیه‌سازی و ضبط می‌شود
  (دیواره‌ها، کف، و مهره‌های روی صفحه به‌عنوان مانع).
- با یک دوران ثابت از ۲۴ دوران مکعب، وجهی که بالا می‌ماند همان عدد قرعه می‌شود → تاس واقعی و نتیجهٔ منصفانه.
- پرتاب‌های کج یا ناپایدار رد و دوباره شبیه‌سازی می‌شوند.
- لحظه‌های برخورد ضبط می‌شوند و صدای تق‌تق تاس دقیقاً هم‌زمان پخش می‌شود.
- هر بازیکن به سمت راست خودش پرتاب می‌کند (مثل تخته واقعی)؛ تاس‌های هر بازیکن هم‌رنگ مهره‌های او.

### ۳. صحنه (scene)
- صفحهٔ چوب گردو با حاشیهٔ **خاتم‌کاری**، نمد زمینه، مثلث‌های منبت با خط طلایی، لولای برنجی، سینی خروج.
- مهره‌ها: هندسهٔ چرخشی با لبهٔ پخ و شیار، متریال براق clearcoat؛ بیش از ۵ مهره → طبقهٔ دوم.
- انیمیشن مهره: بلند شدن، قوس متناسب با فاصله، فرود نرم با جهش کوچک؛
  مهرهٔ زده‌شده با تأخیر به بار پرواز می‌کند؛ مهرهٔ خارج‌شده روی لبه در سینی می‌ایستد.
- تعامل: کلیک/لمس یا کشیدن‌ورها کردن؛ هایلایت مهره‌های قابل حرکت، نشانگر درخشان مقصدها.
- دوربین: ورود سینمایی، تطبیق خودکار با اندازهٔ صفحه (موبایل عمودی ← چرخش ۹۰°)، اختیاری: چرخش ۱۸۰° برای بازیکن فعال.
- نور گرم با سایهٔ نرم، نقشهٔ محیطی رویه‌ای برای بازتاب، Bloom و Vignette؛ حالت کیفیت پایین برای دستگاه ضعیف.

### ۴. رابط کاربری (ui)
- کاملاً فارسی و راست‌به‌چپ با فونت وزیرمتن، عنوان با خط نستعلیق.
- منوی اصلی: نام دو بازیکن، طول مسابقه، رنگ تخته، ادامهٔ بازی ذخیره‌شده.
- نوار بازیکنان: نام، رنگ، شمارش پیپ، امتیاز مسابقه، نشانگر نوبت.
- دکمه‌ها: پرتاب تاس (Space)، برگشت (Ctrl+Z)، پایان نوبت (Enter).
- پیام‌ها: «حرکتی ممکن نیست»، «زد!» و…
- پایان بازی: نوع برد، امتیاز، کاغذ رنگی، بازی بعدی.
- ذخیرهٔ خودکار بازی و تنظیمات در localStorage.

### ۵. صدا (audio)
تق مهره (با تغییر تصادفی زیر و بمی)، برخورد تاس هم‌زمان با فیزیک، ضربهٔ زدن، سُر خوردن در سینی، نغمهٔ پیروزی.

## مراحل پیاده‌سازی
1. موتور قوانین + تست خودکار (حرکت‌های مجاز، قوانین خاص، پایان بازی).
2. بافت‌های رویه‌ای و صفحه.
3. مهره‌ها و سیستم انیمیشن.
4. تاس فیزیکی و هم‌زمانی صدا.
5. وضعیت/کارگردان بازی و تعامل.
6. رابط فارسی، منو، پایان بازی، ذخیره.
7. پرداخت نهایی: دوربین، پس‌پردازش، موبایل، کارایی، تست در مرورگر.
